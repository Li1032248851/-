# Цель работы

## Основная цель

я представлю разбор программной реализации $\rho$-метода Полларда. Основная цель этого эксперимента — решение задачи факторизации целых чисел, то есть поиск нетривиального делителя для заданного составного числа $n$. Этот алгоритм особенно эффективен при наличии небольших делителей и является важным инструментом в криптоанализе.

# Детальный разбор алгоритмов

## Основная функция и генерация последовательности

Ключевой частью моего кода является сжимающая функция f(x).

- Логика кода: Я определил внутреннюю функцию `def f(x): return (x**2 + f_const) % n`.

- Глубокий разбор: Эта функция отвечает за создание последовательности псевдослучайных чисел. Поскольку вычисления по модулю ограничены множеством $S = \{0, 1, \dots, n-1\}$, последовательность неизбежно зацикливается. Именно поэтому метод называется «$\rho$», так как траектория последовательности напоминает греческую букву $\rho$.

## Реализация логики «быстрого и медленного указателей»

Для эффективного обнаружения цикла в коде я использовал логику, похожую на алгоритм Флойда

- Логика кода:

  - `a = f(a)`: это медленный указатель, который делает один шаг за итерацию.

  - `b = f(f(b))`: это быстрый указатель, который делает два шага за итерацию.

- Глубокий разбор: В этом заключается изящество алгоритма. При движении двух указателей с разной скоростью, если существует делитель $p$, то в пространстве по модулю $p$ быстрый указатель обязательно догонит медленный.

## Извлечение НОД

Это решающий шаг в коде, определяющий успех факторизации.

- Логика кода: `d = gcd(abs(a - b), n)`.

- Глубокий разбор: Мы вычисляем наибольший общий делитель разности между значениями указателей и числа $n$. Как только $a \equiv b \pmod p$, разность $|a - b|$ становится кратной $p$. Поскольку $p$ также является делителем $n$, операция gcd извлекает этот потенциальный делитель $p$.

## Определение состояния и завершение цикла

Логика кода:

- if `d == n`: если НОД равен самому числу $n$, это означает, что алгоритм не смог найти нетривиальный делитель при данных параметрах.

- if `d > 1`: если найден делитель больше 1, факторизация прошла успешно, и программа возвращает этот делитель.

- `while d == 1`: пока $d$ остается равным 1, это означает, что указатели еще не встретились ни в одном модульном пространстве делителей, и алгоритм продолжает работу.

# Итоги работы

## Вывод

С помощью этого кода мне удалось успешно воспроизвести пример из лабораторной работы. Для числа $n = 1359331$ код нашел делитель $1181$ всего за 7 итераций. Данная реализация доказывает, что благодаря умелому использованию коллизий в псевдослучайных последовательностях мы можем превратить сложную задачу поиска в эффективное теоретико-числовое вычисление.
